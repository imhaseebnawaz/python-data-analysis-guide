# Python Data Analysis Guide
> "In God we trust. All others must bring data." — W. Edwards Deming

A comprehensive, self-built reference notebook covering the full data analysis pipeline in Python, from raw data to statistical visualization.

## What's Inside

Built across four foundational libraries in a logical learning order:

**Pandas** — data loading, cleaning, filtering, groupby aggregations, correlation, and indexing

**NumPy** — array operations, reshaping, statistical distributions, vectorized math, and memory behavior (copy vs. view)

**Matplotlib** — foundational plotting: line charts, scatter, bar, histogram, pie, box plots, and subplots

**Seaborn** — statistical visualization: distribution plots, categorical plots, regression, FacetGrids, heatmaps, and color theory

## What Makes This Different

Goes beyond surface-level tutorials and covers things most guides skip:

- KDE limitations on bounded and discrete data
- Error bar semantics: spread vs. estimate uncertainty
- Color palette selection by data type (categorical, sequential, diverging)
- NumPy copy vs. view behavior and why it matters

## Who This Is For

Anyone getting started with data analysis in Python and wanting a single reference that takes them from basics to advanced EDA.
